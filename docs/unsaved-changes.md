# 未保存內容與離頁保護

四種工作台共用 `useUnsavedChanges`。表單、LoRA 或遮罩有未保存變更時註冊 `beforeunload`，草稿／遮罩正在保存時也保護；成功保存後才移除對應保護，保存失敗不清除內容。KeepAlive 切頁仍保留表單及筆刷，隱藏工作台的未保存內容也會阻擋整個分頁離開；卸載才移除監聽。

Checkpoint 與 FLUX 可保存完整草稿。局部編輯／Canny 只保留本頁表單，保存原圖或遮罩並不保存整份設定，專用草稿格式仍由 R07 處理。載入任務／作品設定為未保存的新內容；生成不會把表單標為已保存。

取消瀏覽器警示會留在原頁，內容與筆刷不變。確認離開不會呼叫保存或生成。瀏覽器自行決定是否顯示警示文字，通常需要先與頁面互動；行動瀏覽器、系統強制結束程序或瀏覽器崩潰不保證觸發，請主動保存可保存的內容。

待確認的提交由 GenerationPanel 保存原 UUID、body 與端點；重新開啟只顯示原請求恢復操作，不自動重送，也不是未保存草稿的自動備份。
