### N07：分類容量不能由磁碟容量代替

#### 資料範圍與計量

1. 掃描範圍由後端解析既有受管理模型目錄、已登記的額外模型目錄及作品庫輸出。用戶端只傳既有範圍識別，不接受任意目錄作為掃描權限。
2. 平台主機本機路徑與遠端／容器內引擎路徑分開。無法從平台讀取的引擎檔案系統標為「此部署無法統計」，不當成空目錄或 0 GB。
3. 每個磁碟區先保留獨立統計，再在口徑相容時加總。根目錄重疊先消除；junction、符號連結避免循環；硬連結以可靠的磁碟區與檔案身分去重，不能只比較檔名。
4. 模型與作品路徑若重疊，回報歸屬衝突，不能在兩類重複計入，亦不能默認任一類優先。正式實作前需將歸屬規則寫入 API 契約與測試。
5. 清楚區分檔案邏輯長度與磁碟實際配置量。壓縮、稀疏檔與硬連結都可能造成差異；不得直接用邏輯檔案長度扣除磁碟已用量來聲稱「其他」容量。
6. 「其他」只有在同一磁碟區、相容計量口徑、掃描範圍完整且沒有歸屬衝突時才能產生剩餘值；跨磁碟、部分失敗、統計不一致或結果為負時維持未知。分段條不能用預覽比例或估計值補齊。
7. 儲存及傳輸以整數 bytes 為準；畫面以 `bytes / 10^9` 顯示 GB。保留精度與四捨五入規則，百分比只在有效分母下計算。

#### 掃描生命週期與 API 草案

| 建議介面 | 必要行為 |
| --- | --- |
| `POST /api/storage/scans` | 明確啟動背景工作，回傳 scan ID；相同範圍同時只執行一份，讀取頁面不自動觸發全磁碟掃描 |
| `GET /api/storage/scans/{id}` | 回報 `queued/running/completed/partial/cancelled/failed`、範圍、時間、已訪問檔案數與可讀錯誤；不知道剩餘工作時不用假的進度百分比 |
| `POST /api/storage/scans/{id}/cancel` | 合作式取消，立即停止接續遍歷；保留取消狀態，不把部分數字發布為完整分類容量 |
| `GET /api/storage/categories` | 讀取最後可靠快取，包含逐類／逐磁碟區 bytes、計量口徑、完整性、起訖時間、範圍版本及過期原因 |

背景掃描限制併發、記憶體、檔案數與執行時間，避免阻塞生成與主 API。掃描中仍可看上次完整結果，但須標示時間與過期狀態；修改目錄或版本後舊快取不得冒充新範圍。程序中斷後能辨識未完成工作，且不因輪詢或重開頁面重複啟動。

#### 介面接線與完成條件

- 摘要的「尚未統計」連到實際掃描操作與範圍說明；未掃描、取消、部分失敗與真正的空分類是不同狀態。
- 分段條、圖例與明細共同使用同一份分類結果，逐項提供 GB。未知分類不佔據虛構色段，不能將磁碟已用條重新上色冒充分類條。
- 自動測試需覆蓋：空目錄、跨磁碟、重疊根路徑、硬連結、junction 循環、不可讀／消失的檔案、稀疏／壓縮口徑、掃描取消、程序重啟、過期快取與目錄變更。
- 瀏覽器驗收需沿同一份隔離目錄資料完成：首次未掃描 → 啟動 → 掃描中 → 完成 → 更新範圍 → 過期 → 部分失敗／取消。畫面數字必須能由 API 原始 bytes 對照重算。

**目前仍未完成。** 系統頁繼續顯示實際磁碟用量，模型／作品「尚未統計」與其他「未知」保留；沒有代入 820／96／564 GB。

### N05：全域任務抽屜獨立交付

先盤點生成、訓練及安裝工作是否有共同可列舉的任務身分、狀態與事件；若沒有共同協定，先列清支援類型，不將不同來源的最新一筆混成同一進度。遠端引擎失聯、未知與歷史快照都保留來源和時間。

抽屜需有全域入口、待處理數、開關與焦點返回、逐任務進度及明確的原頁定位。應共用單一狀態來源與受控事件連線，避免切頁後累積輪詢。關閉抽屜只停止顯示，不暗中取消任務。停止、取消與恢復仍沿用既有 UUID／後端能力；缺乏能力時禁用並說明原因。

完成驗收至少包含：創作送出 → 切至作品庫仍可查看進度 → 完成後定位原結果；斷線恢復不重複送出；多工作與不同引擎不混淆；關閉／切頁／隱藏視窗後無監聽洩漏。把工作台的任務區移到 fixed 容器不能視為已完成。

### N06：偏好保存獨立交付

可先用本機瀏覽器儲存，鍵名與 schema 版本獨立於草稿、提交恢復及平台設定。只允許顯示密度、具名區塊展開等 UI 欄位；不附帶 prompt、Seed、路徑、引擎地址或任務身分。依使用者已指定的深色、模型清單與作品固定排版作初始預設；保存行為需來自使用者明確調整。

讀取需驗證版本與值，損毀、儲存被禁用或容量不足時回到既定預設，不能阻擋平台操作。提供只重設 UI 偏好的操作，與刪除作品、清除草稿或恢復原提交分離。跨裝置同步若日後需要，另立後端設定契約。

完成驗收至少包含：調整 → 換頁 → 重新載入 → 關閉後重開 → 回復預設；未知版本、損毀值及無儲存權限；核對原草稿與待確認提交完全不變。當次 Vue 元件狀態或 CSS class 均不能等同持久保存。
