**T01／T02 才會定義訓練需求及資料契約；目前沒有開始 LoRA 訓練。** 不可直接把這 20 個不同檔案內容全當作同一角色訓練集：其中有多個角色、重複與差分。畫風訓練需區分人物內容與畫風特徵；角色訓練需先確認每張是否同一目標。兩者都需整理 caption、來源、可用條件、去重群組及獨立評估圖。
