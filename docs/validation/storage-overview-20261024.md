# 目錄與磁碟容量 UI／開啟資料夾驗收（2026-10-24）

本次範圍為系統資訊的目錄與磁碟容量區，改為容量摘要、磁碟使用率及目錄列；資料夾按鈕採附圖的藍色外框圖示方向。API 與操作限制見 [功能契約](../storage-overview.md)。

| 驗證項目 | 方法與結果 |
| --- | --- |
| 1440px 與 390px | 固定容量／長 Windows 路徑、部分容量未知及未建立目錄，無橫向溢出；圖示至少 44×44px |
| 操作與等待 | 桌面 Enter／窄版點擊；請求等待時停用重複操作，只發出一次對應 ID 與快照實際路徑 |
| 錯誤及快照 | 409 不自動重試；GET 失敗保留原路徑及容量並提示舊快照；非 Windows 停用開啟功能 |
| 舊平台程序 | 舊 API 缺少能力欄位時保留路徑、提示重新啟動，不誤判為 Windows 主機不支援 |
| 系統頁無障礙 | 既有整頁掃描於 1440px／390px 通過，包含名稱、焦點、展開及對比；不代表讀屏或完整 WCAG 認證 |
| 後端 | 31 項 storage／model_paths／Windows 別名測試通過；涵蓋本機來源、固定目錄、額外目錄重排／移除、未知目標、過期位置、遺失或檔案目標、UNC 及 OS 失敗 |
| 真實 Windows 開啟 | runtime 隔離平台 `18889`，由瀏覽器點擊「平台資料」；Windows 接受開啟要求，頁面顯示成功訊息；未提交生成 |

最終前端正式建置、格式／靜態與型別檢查通過；5 項新瀏覽器回歸及 1 項既有系統頁無障礙回歸通過。證據位於忽略的 `runtime/quality/browser-results`，另保存 `runtime/storage-overview-desktop-20261024.png` 與 `runtime/storage-overview-mobile-20261024.png`。版面截圖使用測試容量與測試路徑，不當成實際磁碟量測。

實機觸控仍待驗收，390px Chromium 不等於實體觸控裝置。成功回覆表示 OS 接受檔案總管開啟要求，未宣稱驗證視窗是否位於前景。平台正式作品資料未修改；測試程序關閉，原有平台及 ComfyUI 服務不受影響。
