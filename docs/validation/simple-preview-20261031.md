# 簡易創作預覽排版修正

日期：2026-10-31（Asia/Taipei）。

使用者截圖顯示離線結果的畫布過高，保存按鈕與任務列落入畫布。隔離瀏覽器先重現相同狀態：1280px 時畫布底部為 834.59px，容器底部為 671px，元素邊界斷言失敗。

原因是簡易模式固定 480px（窄視窗 360px）的預覽容器，同時沿用進階畫布依視窗高度及比例計算的尺寸；容器沒有包住實際畫布。修改簡易模式的容器及畫布規則，容器依內容增高，畫布使用 `clamp(220px, 45vh, 520px)`，不改其他工作台的尺寸規則。

右側預覽、保存、來源及任務區以單欄格線及明確間距排列。格線使用 `minmax(0, 1fr)`，模型標籤允許斷行，避免離線長訊息或模型檔名撐寬手機版。移除簡易元件內重複的固定高度，保留圖片原比例的 contain 顯示、離線說明、重新讀取、保存與來源操作。
