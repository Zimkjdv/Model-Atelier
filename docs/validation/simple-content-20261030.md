# 簡易創作 11.3：範例、畫風對照與導覽（2026-10-30）

本輪補齊三張卡的真實原配方成果、共同的預設證據顯示、兩份進階畫風練習配方及目前模式分頁的導覽截圖。三張卡仍是既有 v1，沒有覆寫已發佈的模板文字、參數或歷史任務來源。新增的範例觀察獨立保存，不把原先的「待驗收」快照改寫成新的通過聲明。

## 真實生成與資料邊界

使用已在線的本機 ComfyUI，平台任務、素材及作品寫入 `runtime/simple-content-20261030/data` 的隔離資料。每個新案例只提交一次，成功歷史確認後才保存圖片；沒有透過正式平台的 DATA 提交或修改正式模型登記，沒有停止原平台／引擎。當次讀取固定 manifest 的權重檔，核對完整 SHA256 與大小，不將模型登記當作驗檔。

環境為 NVIDIA GeForce RTX 3060 12GB、ComfyUI 0.34.0、Python 3.12.10、PyTorch 2.14.0+cu130。三張原配方 Seed 都是字串 `9007199254740993`；FLUX 使用原 BF16 來源主模型，在工作流選 FP8 e4m3fn 與 CPU 文字編碼器。API 未提供的 CUDA／驅動／Git revision 不補造，完整實際快照保留於各紀錄。

本輪新生成五個 UUID／五件作品，另發布兩張既有自編提示詞的 LoRA 成果。圖片參考素材來自本輪 Animagine 自產圖，經既有素材正規化；沒有發布或使用使用者／作者原圖。八個 PNG 包含五張新成果、兩張歷史成果與一張正規化參考素材，均複製原始 bytes，沒有修圖或用 fixture 代替。

每份 JSON 保留原設定、完整 workflow、精確 Seed、任務／作品 ID、PNG SHA256、權重識別、環境與觀察。三張卡另保留原 `template_context` 與配方 SHA256；兩份進階練習是教學配方 v1，並非新增可一鍵套用的簡易模式卡，也不回填原任務的模板來源。JSON 是實測紀錄，並非一般設定交換封套；使用者依導覽在既有進階流程操作。

第一次 FLUX 前置檢查遇到引擎忙碌，在建立 UUID 前停止，未插入佇列；確認空閒後另立紀錄，只生成一次。圖片參考第一次登記使用 manifest 的大寫架構名稱而被 422 拒絕，未建立生成任務；修正登記格式後另立紀錄。原失敗報告保留於忽略的 runtime，沒有覆寫成通過或重送已提交 UUID。

## 逐圖觀察的範圍

檢視者為開發助手 Codex，已開啟所有發布的生成原圖；這不是使用者品質簽核，沒有自動分數或全面模型排名。

- Animagine：可見單人半身、藍色短髮、白衣與花園，線條／髮部高光清楚。手部未入鏡，不能判定手指或全身比例；沒有指定角色資料，不能認列身份一致或作者相似度。
- Pony：山湖樹林可辨，偏繪畫筆觸。天空與植被偏暖黃橙色，未完全符合 blue sky／peaceful daylight 的預期；風景不外推到人物品質。
- Schnell：小木屋、湖面倒影、針葉林及遠山構圖清楚。只觀察這張 512² 四步圖，不外推細部木構、其他解析度、人物或多人能力；不是 Kontext。
- LoRA：基準提示詞本來就含 pixel art，因此無 LoRA 也呈現像素風。啟用後臉部／高光色塊簡化，也改變眼色與臉型；書本未嚴格合上，手與書連接仍不自然。必須使用已轉換成原生鍵名的固定檔，原始不相容檔曾出圖卻未載入成功，見 [L01 原始證據](style-matrix-20261023.md)。
- 圖片參考：權重 0 保留紅長髮與書店，0.6 帶入藍色髮束與戶外葉片，同時改變臉型及構圖。這顯示內容與畫風可能一起轉移，不能保證只取畫風、鎖定身份或提高權重就更符合文字。

## 介面與導覽

`presetEvidence.ts` 讓摘要與展開詳情直接採後端同一個 `preset.validation`，不再用 Pony ID 特判 Animagine 是否實測。另列目前取樣參數修改、啟用 LoRA、圖片輸入及未知題材範圍；歷史實測與目前登記未驗檔可以同時成立。未知模型沒有預設時保持無資料。

簡易卡顯示原圖縮圖，展開可查看原圖、觀察、環境與下載紀錄；修改描述或 Seed 會標示目前設定已修改。HTML 內直接提供完整英文提示詞與配方，離線不必先開 Markdown。新增簡易截圖，重拍進階與修補截圖，空舞台、色塊遮罩及真實成果分別標示。核對時也修正「輸出沿用原圖」的錯誤標籤：修補遮罩用原圖像素繪製，輸出尺寸可在進階設定另選。
