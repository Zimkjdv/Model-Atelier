# R05 動漫品質基準與提示詞比較（2026-10-23）

本輪完成有限的品質比較與保存／還原驗收：兩個已安裝 checkpoint、三題材、兩個精確 seed、正向品質標籤條件，以及兩種新素材的 denoise 比較，共 18 個獨立 UUID／18 件作品。每張原圖均保留成功與失敗的視覺觀察，沒有自動品質分數、全面模型排名或指定作者相似度通過。

使用者尚未提供目標作者／畫風及同角色參考圖。這批輸入為自行編寫提示詞及本次自產圖片，未下載作者圖片代替目標驗收。指定畫風／角色的使用者目標品質仍待提供資料，提醒規則見[開發計畫](../anime-style-development.md#image-input-reminders)。

## 功能與相容

- 新 `anime-illustration-v1.json` 有半身、全身／服裝、車站場景三案例與四類檢視要點。每個案例的 `character_key` 只作比較分組，不鎖角色。通用插畫 v1 原始 bytes／hash 不變。
- UI 測試集選單、`GET /api/experiments/suite?suite_id=anime-illustration` 與預覽 `suite_id` 明確選取；未知 ID／錯誤案例拒絕。切換清除舊選擇與預覽，過期讀取不得換回舊案例。匯入保存原快照，不替換成目前檔案。
- 新 `prompt`／`negative_prompt` 比較軸只改一個完整文字欄位，使用 schema 2 模型登記快照。正向軸與固定案例不可同選；反向可比較空字串。保留原模型、原引擎、字串 seed、素材與有序 LoRA。模型登記變更的交易核對沿用 R06。
- 舊 schema 1 六軸、schema 2 模型／取樣器／排程器與舊案例凍結文件保持相容。局部編輯／Canny／adapter 不冒充一般比較流程。最多 8 組、每組另載入並明確生成，沒有產品自動批次或重試。

新單組 CLI、重跑與檔案獨占規則見[固定測試集](../illustration-suite.md)；API 使用見[比較方案](../experiment-plans.md)。新增高風險 CLI／測試及 UI 回歸均加入 `quality-scope.json`。

## GPU 條件與矩陣

RTX 3060 12 GiB、ComfyUI 0.34.0（git `15eb748b3ec5f8a0a2d470b7fb280e2d7579f916`）、Python 3.12.10、PyTorch 2.14.0+cu130；使用獨立引擎及平台資料目錄。每組先完整驗證固定來源權重 SHA256／大小與登記，提交一次，失去回應只查原 UUID。沒有 LoRA 或 adapter。

| 組別 | 條件 | 次數 |
| --- | --- | ---: |
| common | Pony V6 XL、Animagine XL 4.0 Opt × 半身／全身／車站 × seed `9007199254740993`、`18446744073709551615` | 12 |
| quality-tags | 各模型半身、第一個 seed；只修改正向品質標籤，其餘保留 | 2 |
| 新素材 denoise | Pony；本次自產半身與車站原圖各自作來源；各比較 0.3、0.6 | 4 |

文字生成共用 1024×1024、28 steps、CFG 5、euler_ancestral／normal、denoise 1、固定反向文字。Pony 標籤沿用平台既有起始提示中的 score／rating／source 成分；固定 Hugging Face 模型卡未附完整使用指南，不稱為已核實的作者最佳格式。Animagine 只加入[固定作者模型卡](https://huggingface.co/cagliostrolab/animagine-xl-4.0/blob/2b7c1b397761bf5bd3cc42e5b39ec99314a75a96/README.md)所列正向品質標籤成分，沒有同步改寫反向、整段標籤順序或 sampler；因此只比較這個文字條件，不能歸因至單一標籤或當作完整作者預設。

圖生圖沿用已驗證單組工具與保存方案：768×768、20 steps、CFG 5.5、dpmpp_2m／karras、第一個 seed、fit。同來源兩組只改 denoise。提示故意要求「無人空房中的紅木椅」，與人物來源衝突，用來觀察來源保留和提示服從的取捨；不是人物轉椅子的品質保證。輸入原圖、正規化素材、生成前處理及每個設定快照均保留。

## 原圖觀察

檢視者為開發助手 Codex，檢視實際原圖及聯絡表；這些筆記不是使用者品質簽核。四類逐圖觀察保存在[證據 JSON](anime-baseline-20261023.json)，未填自動數字評分。

| 面向 | 觀察與失敗 |
| --- | --- |
| 提示服從 | 多數圖有藍外套、紅圍巾、眼鏡和書；Pony 兩個全身 seed 與 Animagine 第一個全身 seed 出現雙人，多張書本打開而非合上。成人特徵亦不能由文字推定。 |
| 角色一致 | 同文字在 seed、題材及品質標籤間改變髮長、臉型和姿態；相同服裝不等於同一身份。小型場景人物的臉部不足以確認。 |
| 畫風 | Pony 在淡色漸層、平塗及場景筆觸間改變；Animagine 的輪廓、亮髮與綠色山景較明顯。標籤改變呈現，不等於提升品質或更像指定作者。 |
| 構圖 | Animagine 第一個車站 seed 較符合偏左人物與遠山；另一組有列車比例／人物靠近軌道的空間偏差。部分半身像裁成近距離胸像；Pony 場景偏右或人物太小。 |
| 素材／denoise | 0.3 大致保留原人物與場景，沒有遵從紅木椅提示。0.6 改動更多，但仍保留人物；半身來源出現嚴重臉部／手部扭曲，場景來源空間結構亦失真。增加像素變化不代表品質改善。 |

文字組提交至成功歷史的觀察時間為 23.391–42.406 秒，引擎歷史為 22.303–41.017 秒；圖生圖為 11.969–28.047 秒／10.282–27.067 秒。這些包含冷／暖載入、佇列、網路和觀察開銷差異，不是純 GPU 基準或速度承諾。各任務凍結量測保留，`task_vram_peak_bytes` 未知；整卡／引擎觀察不可替代任務專用峰值。

## 保存、離線與驗證

完整原圖、18 份報告、2 個素材及 2 份 denoise 保存方案位於 `runtime/r05-live-20261023/`。每份報告保留唯一 request/job ID、完整 workflow、精確 seed、原圖 hash／尺寸、版本、原設定還原與量測。證據 JSON 收錄每次的模型／環境／素材／設定、原始 workflow 下載 bytes hash、報告 hash 及觀察；重複的還原設定與資源樣本以摘要 hash 連回完整原報告，不改舊快照。

停掉本次引擎及平台後，使用同資料目錄重啟平台。18 份報告皆僅 GET 核對，禁止讀取權重、同步、生成或匯入；前後維持 18 任務／18 作品／0 草稿。正式 DATA 八個檔案的 hash 在啟動前、停止後及重啟結束後一致；本次測試服務已停止。

格式／靜態檢查、605 項後端（1 項既有跳過）、Vue 型別／建置、四組前端契約及全部 91 項 Chromium 通過。新增 6 項後端涵蓋案例版本／hash、舊新快照、單一文字變因、數值正規化、精確 seed、未知／非法輸入、一次提交、錯誤報告不查詢與 GET-only 恢復；新增 1440px／390px 操作測試涵蓋切換、保存及手動載入零生成，已檢視兩尺寸截圖。

R05 關閉範圍是這一批可重現的有限比較及品質限制紀錄。指定作者／使用者角色品質、更多模型／素材／seed、RTX 4080 與訓練仍未驗收；圖片到齊後沿同契約建立新批次，不把這些結果當作全面品質通過。
