## 環境與搬移

Windows 11 build 26200；Python 3.12.10、Node 22.23.3；RTX 4080，CUDA 回報 17,170,956,288 bytes 顯存，NVIDIA 管理介面回報 17,171,480,576 bytes；RAM 68,388,212,736 bytes；C 磁碟總容量 1,022,021,857,280、快照可用 690,401,591,296 bytes。容量來源不同，保留原值。驅動 617.42、Torch 2.14.0+cu130、CUDA Runtime 13.0，ComfyUI 0.34.0／`15eb748b3ec5f8a0a2d470b7fb280e2d7579f916`。

平台及 ComfyUI 原 `.venv` 指向舊使用者的 Python。以本機同版 Python 更新 venv 解譯器設定並重建啟用腳本，保留套件後執行兩套 `pip check`；平台 lock 核對、frontend `npm ci`／build 成功。沿用已搬移權重，沒有重下載模型或改寫歷史 run 路徑。

獨立引擎只綁定 127.0.0.1:8188，平台在 8000。裝置回報確認 CUDA index 0；引擎日誌記錄 SDXL 模型／CLIP float16、VAE bfloat16、CPU offload。實際 kernel 累積精度未取得，保持未知；這些觀察不代表其他模型、流程或最低容量。

## 真實生成與保存

沿用 RTX 3060 驗收器及固定模型／參數，batch 均為 1，精確 seed 均為字串 `9007199254740993`。每例先保存新 UUID，再只提交一次；確認 successful history 後匯入原圖，解碼並核對圖片尺寸／SHA256、完整 workflow、模型版本與逐欄設定還原。

新增輸入是自製幾何椅子及二值遮罩，SHA256 與前處理在 JSON。這些案例確認流程可執行，並未以幾何圖判定作者畫風、身份或圖像品質；也不把新輸入當成兩台相同來源圖片的效能對照。Pony／Animagine／LoRA 固定設定對應既有驗收器；跨機效能比較另見 E03。

Canny 首次在送出 UUID 前因「Fixed weight metadata differs」拒絕，沒有 GPU 提交。原因是正式 DATA 尚未登記固定 ControlNet 身分；同步並補登 manifest 的版本／大小／hash 後，以新報告成功。原失敗報告保留，不覆寫成通過。

## 瀏覽器與離線

Chromium 在 1440px 瀏覽系統頁、辨識 RTX 4080、開啟本次 Pony 原圖，再載入創作表單；390px 核對 seed 仍為完整字串。整段操作沒有 `/generate`，沒有 page error。截圖與機器結果保存為 `runtime/e02-system-20261026.png`、`e02-gallery-20261026.png`、`e02-restore-390-20261026.png` 及 `e02-browser-20261026.json`。

確認引擎佇列空白後，只停止本次擁有的引擎程序；八份報告全部以 GET-only 原驗收器重新核對任務、作品、原圖 hash 與還原設定，全部通過。其後使用原啟動腳本恢復引擎。沒有重跑歷史 UUID。

## 重跑與界限

```powershell
.\.venv\Scripts\python.exe -m scripts.verify_hardware snapshot --report runtime/my-environment.json
.\.venv\Scripts\python.exe -m scripts.verify_hardware run --case pony -- --report runtime/my-pony.json
.\.venv\Scripts\python.exe -m scripts.verify_hardware run --case animagine -- --report runtime/my-animagine.json
.\.venv\Scripts\python.exe -m scripts.verify_hardware run --case multi -- --report runtime/my-multi.json
# image／inpaint／canny 使用明確匯入的 source UUID；inpaint 另需 mask UUID。
# 在原參數末尾加 --verify-report，只 GET 既有報告，不提交生成。
```

新工具與測試加入 quality scope，原因是它控制驗收提交及來源摘要。完整品質入口驗證格式、靜態檢查、後端、前端建置／契約與隔離 Chromium；實際數量記於 CHANGELOG。
