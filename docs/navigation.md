# 網址導覽、首次使用與能力狀態

頁面／工作流程使用 hash URL，可直接開啟、重新整理及返回／前進，不需要伺服器 rewrite 或額外 router 依賴：

| 畫面 | 網址片段 |
| --- | --- |
| 系統資訊／首次使用 | `#/system`（空網址亦正規化至此） |
| 四工作台 | `#/studio/checkpoint`、`#/studio/flux`、`#/studio/inpaint`、`#/studio/control` |
| 模型／參考素材 | `#/models`、`#/assets` |
| 作品／選定匯入任務 | `#/gallery`、`#/gallery?job=<UUID>` |
| 連線設定 | `#/settings` |

錯誤路徑、流程或額外參數會顯示提示並替換成系統資訊。網址只表示導覽／選定任務，不包含表單、提示詞、圖片、引擎憑證，也不觸發生成、匯入或恢復原提交。作品庫的 job 是待匯入任務選項，不會自動匯入圖片。

所有站內導覽與工作台事件使用同一入口；切換後焦點移到主要內容，頁面標題、`aria-current` 與流程 `aria-pressed` 隨之更新。跳至主要內容連結只移動焦點，不改網址。四 Studio 仍由 KeepAlive 保留站內表單；重新整理會重建記憶體，未保存內容遵守 [Q05 離頁保護](unsaved-changes.md)，網址本身不是草稿備份。作品未保存筆記／評分時，返回或點擊導覽均需明確確認；取消恢復原歷史位置、網址及筆記。

系統、設定與工作台提供「連線 → 選模型 → 建立作品」指引，工作台預設收合以保留表單空間。連線顯示已連線、離線或未知；模型同步／登記不代表已載入權重。生成區依原本的 blocking 條件呈現「載入／處理中」「尚缺必要條件」「表單預檢可提交」及「原提交待確認」，沿用既有 disabled 判斷，不另建較寬鬆的提交規則。實際缺項提示保留於下方，詳細能力範圍可展開。

FLUX 已有專用程式流程但實機 GPU 尚未驗證。其他流程仍只按對應文件的硬體、模型、參數與日期判讀；版本／來源／檔案 hash／執行裝置無法取得時保持未知。模型與任務的詳細來源／版本快照沿用原有展開區。沒有以「可提交」替代品質、授權或 GPU 驗收。
