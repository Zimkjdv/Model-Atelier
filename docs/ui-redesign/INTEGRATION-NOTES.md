## 作品選取與比較流程修正

作品選取先顯示與 `preview.html` 相同的深色操作列：已選件數、並排比較（2–4 張）、批次封存／還原、批次下載原圖與清除選取。選圖不再展開比較區；按「並排比較」才進入 `#/gallery/compare`。返回作品庫時，保留選取、搜尋、篩選、排序、排版及目前分頁。網址只記錄畫面，重載後沒有選取時顯示返回指引，不自動挑選作品。原圖、人工評分、精確 Seed、有序 LoRA 與完整參數差異均保留。

批次管理最多選取 100 件，比較仍限制 2–4 張。封存／還原重用既有逐件 revision 檢查；成功項目移出選取，衝突與未處理項目保留。逐項列出錯誤，提供只讀的「重新讀取選取狀態」，由使用者確認後再執行。網路中斷或結果不確定時停止後續保存，不自動重試。「停止後續操作」等待目前一件完成後停止，不撤回已成功的項目。

原圖批次下載經只讀 `POST /api/artwork-downloads` 打包 ZIP，使用已保存的 UUID 檔名，保留原始位元組與中繼資料，不連接引擎。一次最多 100 張、合計 256 MiB；缺檔、未知作品或打包失敗時不交付部分 ZIP，也不清除選取。較大的批次可分批下載。

比較與作品庫之間的瀏覽器返回／前進仍會檢查未保存筆記及評分；取消離開時保留表單及目前網址。接受離開時關閉詳情視窗，避免已離開畫面卻仍顯示舊視窗。

### 結果讀取界線

新增唯讀 `/api/jobs/{job_id}/results` 與 `/api/jobs/{job_id}/results/{index}/image`。只能取得成功且屬於平台原任務、原工作流程所記錄的 SaveImage 結果。重用既有輸出檔名／路徑與圖片驗證，限制單張 32 MiB、3200 萬像素，不接受任意引擎網址、路徑或輸出檔名。結構流程保留既有主要結果節點篩選。

預覽不建立作品紀錄、不寫入圖片、不重新生成、不重試提交。原圖匯入仍需使用者明確操作；讀取未保存圖片需要任務原引擎可用。顯示圖片不代表模型品質已通過驗證。

## 2026-10-29：資訊與操作G05／G06／P01–P03

### G05：作品庫資訊與清單控制

- 卡片補上建立日期及人工評分摘要。平均值只計算已評項目，並顯示「已評 N／4 項」；沒有評分時顯示「尚未評分」，不把空值計成零分。
- 清單 API 只投影四個固定評分欄位，頁面重新讀取時取得最新值，不為每張卡額外載入完整 workflow 或來源快照。
- 顯示「符合張數／全部張數（含封存）」、目前頁與本頁張數。新增 `all_total`，和篩選結果在同一唯讀交易取得；翻頁沿用該清單快照的總數。舊回覆缺少此值時顯示未知。
- 每頁可選 4／12／24 張，預設 12 張。更改筆數重新取得清單，不沿用舊游標；排序、搜尋、版型與跨頁選取繼續保留。
- 搜尋無結果提供「清除搜尋與篩選」，清除搜尋、模型與收藏條件，保留目前使用中／已封存／全部作品範圍。空庫與尚無封存作品使用不同提示。

### G06：素材空狀態

搜尋無結果提供「清除搜尋與用途篩選」，保留使用中或已封存範圍。未指定搜尋、且素材庫為空時，顯示收集第一張參考圖與上傳入口；封存範圍為空時說明封存與還原。清除操作遵守原編輯／保存保護。

### P01：欄位預檢與處理入口

- 文字／圖片創作、FLUX、FLUX 附加、局部修補、結構引導、風格參考共用基本輸入預檢：名稱、文字長度、模型／必要元件、來源、尺寸、精確 Seed、步數及數值範圍；專用流程另涵蓋遮罩、參考權重／範圍、控制強度／範圍與 Canny 閾值等欄位。
- Seed 以十進位字串檢查到 `18446744073709551615`，不轉成 JavaScript number。空提示詞沿用現有 API 契約，不自行改成必填。
- 每個錯誤顯示在對應控制項後方，關聯 `aria-invalid`／`aria-describedby`；修正後移除錯誤關聯。預檢不改寫輸入值。
- 提交區分開列「流程與環境阻擋」及「需修正欄位」。欄位按鈕會展開所在進階區、捲動並聚焦；引擎、模型及元件問題有處理入口。Checkpoint 可直接明確更新引擎選項。
- Checkpoint 將原本逐項提前回傳的環境條件改為收集顯示；其他專用流程在保留原完整流程判定的同時，另列引擎／清單／能力條件，避免欄位錯誤遮住同時存在的環境問題。
- 表單欄位改為獨立捲動區，提交區保留在欄外，避免錯誤摘要變長後遮住剛定位的輸入框。三種桌面尺寸仍對照原預覽的主要位置。
- 原有模型、LoRA、來源尺寸、專用節點及後端最終驗證繼續生效；API 請求錯誤保留原訊息。恢復未確認請求仍使用原 UUID／凍結參數，不因目前表單錯誤而重建或阻擋原請求恢復。

### P02：訓練執行摘要

「執行與產物」將摘要放在主要位置，顯示原 run 名稱、狀態、目前／總 steps、比例與讀取時間，旁邊說明完成後的產物與比較流程。可選擇既有 run、明確更新摘要，或定位到原日誌及產物操作。

優先使用回報的完成步數；只有最後 checkpoint 步數時明確標示來源。沒有可靠步數或總量時顯示未知且不畫比例；步數超出凍結上限時顯示異常。更新失敗保留原快照與讀取時間，不清成零或假裝正在更新。

完整 UUID、原請求恢復、啟動／停止／續訓、凍結設定、資源、日誌、receipt 與固定比較仍在下方。摘要只讀狀態，沒有自動開始、停止、安裝或生成。進入此階段時，如沒有已恢復的 run，會唯讀載入清單中的最近紀錄。

### P03：設定匯出引導

設定 → 資料與隱私新增 Checkpoint／FLUX 設定匯出／匯入入口。前往對應工作台後，保留快取參數、展開既有交換區並顯示匯出按鈕；FLUX 若先前停在附加流程，會回到支援此交換格式的基本流程。

前往入口不會自動保存、套用、下載或生成。使用者仍需明確匯出 JSON。介面說明 JSON 包含創作使用的引擎位址與參數，並區分平台整體設定、作品、素材與模型備份；沒有新增一個名不符實的完整平台備份按鈕。

以上行號是原基準定位，後續已改動。預覽含後段覆寫，原核對以studio、library（原381起）、detail及assetLibrary等最後版本為準，不能用前段舊函式誤判。P1／P2表示主流程或次要呈現優先級，不是安全等級。

舊[preview-alignment測試](../../frontend/tests/preview-alignment.spec.ts)比較x／y／width、欄數、第一圖示等，模型偏重Checkpoint、舞台比的是空畫布；通過不能證明其他分類／完成結果已接通。整合根元件保住功能，也不代表子分類／後段階段皆重排完成；後來才補[逐狀態旅程與分類矩陣](ACCEPTANCE.md)。這是可查的驗收缺口，不推測開發者動機。

當時逐頁核對亦確認：[UiIcon](../../frontend/src/UiIcon.vue)共用SVG及五目的、進階／草稿仍在；修補有真實[MaskEditor](../../frontend/src/MaskEditor.vue)，不能由共用空畫布推定遮罩也沒有圖片。作品收藏／筆記／評分／封存及右上封存／關閉仍在；`3d55c0c`已先操作列再比較。素材管理、五模型分類、訓練四階段／待補／最終評估保護、系統四分頁／環境、設定五類與診斷也不是整體消失。淺色、英文與清快取在原型未真正開放，不能誤列為遭刪功能。

[ExperimentPlanner](../../frontend/src/ExperimentPlanner.vue)原269起與[ExperimentResults](../../frontend/src/ExperimentResults.vue)原114–144仍有方案摘要、steps卡、人工評分和載入；正式「載入設定」再手動生成符合不自動提交限制，空方案不應塞示意結果。[SystemWorkspace](../../frontend/src/SystemWorkspace.vue)原208–221只有實際磁碟用量條，分類「尚未統計／尚未統計／未知」；缺可靠API解釋未知，卻不代表N07已完成。原工作台任務不等於N05跨頁抽屜，當次排版狀態不等於N06跨次偏好，三項保持獨立。

原訂補齊次序是G01–G04→G05／G06／P01–P03→獨立列N07／N05／N06→同隔離資料旅程→分類／階段／目的矩陣；目前完成及剩餘狀態見頁首，不以自行分期當成使用者已驗收接受所有延後。
