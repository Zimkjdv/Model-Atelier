# 參考文件整合決策 · v3

日期：2026-10-27。依使用者提供的 `model-atelier-ui-v2.html` 與 `ui-review-suggestions-v2.md` 整合。**整體視覺以提供範例為準，功能範圍以現有平台與 FEATURE-INVENTORY.md 為準。** 原始提供檔案未修改。

## 已採納

- 72px SVG 圖示導覽，保留簡短中文標籤與完整 accessible name；窄螢幕改可橫捲導覽。
- 單一精簡頂列，放目前頁面、引擎狀態、預覽情境及原型說明。取消大型設計橫幅，連結移入說明視窗。
- 工作台直接呈現左設定／右畫布，不再放大標語。桌面設定欄 340–410px，右側畫布佔剩餘空間，採最暗表面；移除雙層畫布卡片、全大寫英文 eyebrow、無先後意義的任務編號與裝飾 Study 字樣。
- 設定順序為目的 → 來源（適用時）→ 描述 → 模型 → 尺寸 → 進階。尺寸按鈕有比例形狀、像素與 MP；生成操作固定於設定欄底部（窄版順流呈現，避免遮擋）。
- 一個淺綠強調色、深字主按鈕、亮黃 focus ring。背景／導覽／面板／選取以亮度分層，暖色留給需處理狀態。
- 作品庫可切換瀑布流與固定方格，兩者共用搜尋、模型、收藏、封存篩選與選取狀態。最多四張比較；真實比例並排，固定縮圖裁切不改原圖。
- 作品詳情補像素尺寸與 MP；收藏、封存／還原可在原型記憶體操作。下載保留入口但不偽造真實原圖或 workflow。
- 素材按用途帶往結構或畫風／角色流程，保留具名來源，仍需明確生成。
- 局部修補提供筆刷、擦除、清除與可鍵盤操作的中央區塊示意；遮罩保留於本頁，切換流程再回來不會清空。
- 實驗明示固定尺寸、模型、提示詞與 Seed；訓練才保留有實際順序的階段編號。
- 缺元件只停用受影響架構（本例 FLUX 缺 VAE）；不再全域停用 SDXL。離線停止生成，但保留離線整理。

| 文件建議／範例 | 整合決定與原因 |

## 範例之外補回的內容

- **系統五區完整保留**：平台主機；目前選定引擎；目錄與磁碟容量；本機 ComfyUI 安裝檢查；部署與存取。
- **實際目錄集合**：平台資料、參考素材、作品庫輸出、受管理 checkpoint、ComfyUI 輸出與額外 checkpoint，依 backend/storage.py；多磁碟去重合計、部分未知、實際路徑及開啟資料夾。
- **設定**：額外 checkpoint 可編輯、上限 8 個、保存／重新讀取、衝突與未保存保護、作用範圍、手動重啟後同步；診斷的任務 UUID 與請求 ID 分開保留。
- **任務及作品詳情**：歷史來源／依賴版本／執行裝置、流程 hash、元件與素材快照、耗時與連續資源取樣；不以目前主機值回填。
- **其他原能力**：設定交換、原 UUID 恢復、取消／停止、預設差異確認、有序 LoRA、FLUX 預檢、資料集版本、續訓、產物回登等，依功能對照表保留名稱、位置與原行為。
