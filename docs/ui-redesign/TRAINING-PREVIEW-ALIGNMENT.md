日期：2026-10-29。驗收基準為本目錄原有 `preview.html`；本輪沒有修改預覽，也沒有新增手機版範圍。正式平台保留審查、資料包、獨立訓練環境、原 UUID、停止／續訓、產物與報告能力。

## 保留的必要差異

- 預覽只有三個匯出檢查列；正式版另列原圖與其他完整性，保留角色、完整性與未識別的新阻擋碼。判定仍由後端 `readiness.data_ready`、已保存修訂與原有未保存／忙碌限制共同控制；顯示通過不代表品質或授權認證。
- 預覽可選示意基礎模型；正式訓練基底固定為 Animagine XL 4.0 Opt，顯示唯讀欄位，不提供無效的模型選擇。尺寸、rank、總 steps、保存間隔、learning rate、seed、GPU index 及用途全部保留。
- 審查保留最終評估、來源審查人、用途依據、角色身分、曝光紀錄、版本衝突與原圖完整性；沒有照預覽刪成少數欄位。
- 預覽的 620 / 1,000 是展示數字。正式版只讀原 run 的步數；0 是合法進度，未知不顯示成 0%，讀取失敗保留上次快照。
- 停止、開始、續訓、安裝與固定比較仍沿用原有後端及資源限制。「前往實驗比較」只導覽，不建立方案或生成圖片。
- 進階參數、UUID、run、receipt、日誌、資源與報告仍有具名入口；進入頁面及切換階段不會自動開始訓練。

## 實際驗證

- 正式建置、範圍內格式／TypeScript／CSS 檢查通過；主 JS 超過 500 kB 的既有建置提醒仍存在。
- 11 個不同瀏覽器案例通過。四階段在 1280×800、1440×900、1920×1080 逐一驗收，共 12 格；另覆蓋空資料、後端讀取失敗、未保存離開取消、保存失敗不切圖、125 張資料導覽、篩選與保留圖不曝光。
- 三尺寸沿同一隔離資料集完成審查、保存新修訂、train-only 匯出，再用同一匯出身分驗收準備與執行摘要。另有模擬的原 UUID 恢復、停止、新 run 續訓及產物流程回歸。
- 新增檢查包含四組檢查列、收合參數的瀏覽器預檢、固定基底、日誌／產物展開與焦點、歷史報告入口、實驗比較導覽、未知與失敗快照、無障礙。
- 全部使用新的臨時 DATA 與模擬引擎；沒有修改正式資料、啟動實際 trainer 或生成圖片。模擬啟停回覆只驗證介面契約，不宣稱訓練品質或模型安裝實機驗收。
