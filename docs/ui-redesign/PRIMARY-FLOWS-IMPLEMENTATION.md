# G01–G04 主要流程補齊紀錄

日期：2026-10-29。依 [落差分析](PREVIEW-IMPLEMENTATION-GAP-ANALYSIS.md) 本輪先實作 G01、G02、G03、G04。原型 `preview.html` 維持核准版本。

## 完成內容

| 項目 | 正式行為 |
| --- | --- |
| G01 主舞台結果 | 文字創作、圖片重繪、FLUX 與風格參考接入實際任務結果。可從最近任務或歷史任務選擇舞台內容；一個任務有多張結果時可切換。顯示原任務 UUID、實際圖片尺寸與保存狀態，修改表單尺寸不改變舊結果比例。 |
| G01 專用編輯器 | 局部修補提供「遮罩編輯／生成結果」，結構引導提供「結構預覽／生成結果」。切換保留編輯器實例及未保存遮罩，不以結果元件取代原編輯功能。 |
| G01 狀態與來源 | 等待、生成中、未完成、讀取中、結果不可讀分別呈現；失敗可明確重讀。已保存原圖優先從平台讀取，可離線查看；未匯入結果只向任務原引擎讀取，不跟隨後來更改的引擎設定。已匯入但本機原圖遺失與從未匯入分開標示。 |
| G02 全分類版型 | Checkpoint、LoRA、結構控制、參考元件、FLUX 元件共用「清單／卡片」切換，初次進入預設清單。版型切換保留分類與編輯值；原授權、來源、hash、架構相容性及驗證工具仍保留。 |
| G02 元件檢視 | 參考元件新增可瀏覽的模型列／卡片，編輯入口連到原登記表單；FLUX 保留角色分組與準備計畫。LoRA／結構控制的搜尋、來源與相容性工具收在具名展開區，清單先呈現模型。 |
| G03 分類同步 | 頂部按鈕隨分類改名及呼叫該類專用同步，分別使用 `/api/models/sync`、`/api/loras/sync`、`/api/controlnets/sync`、`/api/reference-components/sync`、`/api/flux/components/sync`。頁內重複同步入口於整合模式收起；其他工作台重用的元件維持原入口。處理中或該分類仍在編輯時不允許同步覆蓋。 |
| G04 素材詳情 | 點圖開啟原生對話視窗，顯示大圖、用途、尺寸、像素量、大小、前處理及封存狀態。保留另開原圖、用於創作、編輯、封存／還原。 |
| G04 保存保護 | 保存沿用原 revision 契約；衝突不覆蓋表單。未保存時關閉、Escape、離開路由及關閉分頁有保護；保存處理中不關閉視窗。關閉後返回對應素材卡，包含封存／還原造成清單重建的情況。 |

## 結果讀取界線

新增唯讀 `/api/jobs/{job_id}/results` 與 `/api/jobs/{job_id}/results/{index}/image`。只能取得成功且屬於平台原任務、原工作流程所記錄的 SaveImage 結果。重用既有輸出檔名／路徑與圖片驗證，限制單張 32 MiB、3200 萬像素，不接受任意引擎網址、路徑或輸出檔名。結構流程保留既有主要結果節點篩選。

預覽不建立作品紀錄、不寫入圖片、不重新生成、不重試提交。原圖匯入仍需使用者明確操作；讀取未保存圖片需要任務原引擎可用。顯示圖片不代表模型品質已通過驗證。

## 實際驗證

- 後端 11 項測試通過：5 項新結果讀取測試與 6 項原作品匯入測試。涵蓋原引擎綁定、預覽不寫入、保存原圖離線取得、原圖缺失、非法路徑／索引、未完成任務、不可解碼圖片、容量限制與引擎離線。
- 新增 5 項瀏覽器案例通過：實際尺寸不隨表單改變、離線保存圖、失敗重讀、五類同步／版型及編輯保留、素材保存／封存／焦點／關閉保護、revision 衝突與離開保護。
- 受影響回歸共 8 個不同案例通過：三種桌面尺寸、工作台狀態與精確 Seed、跨頁模型／素材帶入、參考元件保存回讀、遮罩像素／保存，以及管理頁自動無障礙規則。其中遮罩案例加入來源與結果切換後像素不變的檢查。
- 正式前端建置、既有 `npm test` API／生命週期／實驗／遮罩／控制契約檢查，以及範圍內 Python 格式／lint、前端格式／型別／CSS lint 通過。不是完整瀏覽器套件或完整人工無障礙驗收。
- Vite 主 JS 約 556 kB，仍有超過 500 kB 的既有分包提醒；本輪沒有另做載入拆分。
