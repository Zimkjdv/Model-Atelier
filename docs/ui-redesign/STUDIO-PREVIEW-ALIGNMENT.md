## 保留的正式版差異

- 來源仍使用真實素材選單與搜尋／分批清單；沒有把原型的示意挑圖按鈕接到不存在的選擇器。封存、消失素材及原身分檢查保留。
- 模型架構、Checkpoint 登記與 FLUX 四元件仍分開。FLUX LoRA／VAE 圖生圖沿用固定配置與獨立格式；沒有新增假模型選項、未知元件支援或任意混搭。
- 專用修補、結構、參考流程保留原有元件、模型、尺寸及相容性限制。局部修補還保留 Fooocus 實驗流程、羽化、PNG、復原／重做及來源切換確認，因此工具比原預覽多。
- Pose／Depth 此處顯示的是原圖；條件圖由原引擎產生。Canny CPU 預覽仍是本機近似結果，不冒充原任務實際條件圖。CPU 計算、保存遮罩及生成各自需要明確操作。
- 右側生成結果仍讀取原任務的真實輸出尺寸、保存狀態與多輸出選擇，不使用目前表單尺寸重解釋舊結果。草稿、精確 Seed、參數交換、來源快照、實驗方案及失敗原 UUID 恢復全部保留。
- 保留既有文字模式行為：切換成文字創作會清除當前圖生圖來源選取；Denoise／縮放數值保留，再回圖生圖需重新選圖。本輪沒有改寫這項安全行為。
- 「任務與歷史資訊」仍開啟原工作台任務內容。[N05 全域任務抽屜與 N06 偏好保存](BACKEND-CAPABILITIES-BACKLOG.md) 維持獨立未完成，這次工具入口與排版不代表它們已交付。

## 分目的及架構驗收

以下各列都在三種桌面尺寸驗收；這是介面與既有契約驗收，不是所有模型的 GPU 效果實測。

| 目的 | Checkpoint | FLUX |
| --- | --- | --- |
| 文字創作 | 描述／模型／四種尺寸／進階／草稿與交換；保留精確 Seed | 獨立 Schnell 四元件文生圖，補上四種尺寸預設；實際生成仍受既有元件與環境預檢限制 |
| 圖片重繪 | 來源先於描述；Denoise、等比補白／拉伸可編輯並保留 | 使用獨立 VAE 圖生圖，512×512／4 步／FP8／CPU 固定配置；Denoise 必須小於 1 |
| 局部修補 | 一般修補與 Fooocus 選項仍存在；缺遮罩時停用提交，遮罩／結果可切換 | 不提供 FLUX 修補；導覽至獨立 Checkpoint 修補流程，不轉換 FLUX 參數 |
| 結構引導 | Canny／Pose／Depth 各自可選；原圖可見、CPU Canny 只在明確操作時計算 | 不提供 FLUX 結構控制；使用獨立 Checkpoint 流程 |
| 風格參考 | SDXL 畫風／角色外觀分開，保留 IP-Adapter 與影像編碼器預檢 | 不提供 FLUX IP-Adapter；使用獨立 Checkpoint 參考流程 |

另驗證 FLUX LoRA 附加流程的相容性入口與固定配置；沒有將它混入一般文生圖或圖生圖。
