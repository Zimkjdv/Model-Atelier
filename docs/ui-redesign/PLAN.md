## 資訊架構與原則

作品為主，必要設定在旁，技術追溯放具名詳情。目的、架構與流程能力分層；作品、參考素材和訓練圖片分開，轉用必須明確操作。連線、清單登記、可執行及限定實測是不同狀態。

| 分組 | 頁面 | 主要用途與操作 |
| --- | --- | --- |
| 創作 | 創作工作台 | 選目的、設定、手動生成、檢視原任務結果 |
| 創作 | 作品庫 | 明確匯入、整理與重用成果 |
| 創作 | 實驗比較 | 建立固定條件方案，逐組載入後手動生成 |
| 資源 | 參考素材 | 上傳、整理用途與明確帶入 |
| 資源 | 模型庫 | 五分類同步、來源登記與相容性工具 |
| 資源 | 訓練工作區 | 審查、匯出、準備、執行與產物 |
| 管理 | 系統資訊 | 來源清楚的即時資源與需處理項目 |
| 管理 | 設定 | 連線、模型路徑、資料說明與診斷 |

不另增儀表板。未就緒時提供連線→準備模型→創作的引導；既有網址、返回、重整、KeepAlive、dirty 保護與原 UUID 恢復保留。沒有結果、沒有資料或未知能力時，不能放入原型假圖與假進度。

## 共用視覺與無障礙

- 參考已有的 icon 必須沿用原 SVG 路徑、尺寸與風格；原型沒有而正式版已有的功能可保留圖示。72px 側欄、54px 導覽按鈕、22×22px SVG、1.7 線寬、12px 標籤；M 標記 40×40px、12px 圓角、22px 字體，導覽圖文 gap 3px、項目 gap 4px。
- 全頁只留頂欄一個 h1。一般頁頂欄 62px／標題 20px，系統頁 57px／18px；移除重複頁名、eyebrow／A NEW BEGINNING 的輸出。一般內容左右 28–32px，卡片內距 20–24px、12–16px 圓角、1px 邊框；陰影留給浮層。
- 共用狀態與控制項來自 [theme.css](../../frontend/src/theme.css)，核准桌面外觀由 [redesign.css](../../frontend/src/redesign.css) 覆寫，頁面元件保留特有布局。現行字體 Noto Sans TC／Microsoft JhengHei／PingFang TC／system-ui；表單與按鈕繼承字體。早期 Inter／Segoe UI 與 11px 側欄是歷史規格。
- 現行色票：背景 `#0f1412`、側欄 `#121a17`、面板 `#182019`、升高表面 `#212c25`、舞台 `#0a0e0c`、邊框 `#2c3a32`、主字 `#e8efe9`、次字 `#bccabf`、弱字 `#93a69a`、強調 `#b9d3a4`／深字 `#13200f`、暖色 `#e0b98a`、焦點 `#f2d58a`。主操作淺綠實心、次操作深底描邊，琥珀色用於真正需處理狀態。
- 一般內容 14–16px、次要說明通常至少 13px；區塊標題 17–20px，繁中行高約 1.6。技術碼、路徑、Seed 用等寬；列表長名稱單行 `…`，hover／鍵盤焦點提供完整 tooltip；詳情內完整路徑可換行，大表格可局部橫捲及聚焦。
- 一般文字對比至少 4.5:1，大字至少 3:1；控制邊界與焦點至少 3:1。深色漸層須核對最亮端，不能只看自動 violations。圖示有可讀名稱、狀態附文字，`aria-pressed` 為布林而非資料庫 0／1。
- `.notice`／`.warning`／`.success` 分層；非緊急結果以 polite `role=status` 公告，錯誤使用合適 `role=alert`／live region，不任意中斷工作。[W3C 狀態訊息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)。載入說明動作，空清單提供下一步。
- 保留 2px `focus-visible`、減少動態效果偏好、disabled 狀態；main 的切頁／跳到內容焦點不畫成控制外框。分頁以 tablist／tab／tabpanel、aria-selected、單一 Tab 入口，支援左右鍵及 Home／End。彈窗有 Escape、初始焦點及返回觸發點；未保存或保存處理中遵守原保護。

## 創作工作台

左側設定約 410px，右側近黑舞台佔剩餘空間；主操作在設定欄底部，欄位獨立捲動，任務摘要在舞台下方。不以隱藏預檢或移除正式功能換取首屏高度。

五目的為文字創作、圖片重繪、局部修補、結構引導、風格參考；下層再分 Checkpoint／FLUX，使用不同表單與契約。主要順序：**目的 → 來源（適用時）→ 描述 → 模型 → 尺寸 → 結構方式／參考目的（適用時）→ 進階**。來源、描述、模型使用同一圖示排列；字數獨立成標籤。選中目的淺綠底深字，其餘深底與 hover；這是後續正式版美化，原 preview 不跟改。

| 目的 | 必要操作與界線 |
| --- | --- |
| 文字創作 | Checkpoint／Schnell 獨立；FLUX 是四元件，不是 checkpoint loader |
| 圖片重繪 | 真實來源選擇；Denoise、縮放、處理後預覽在進階；不等同身分鎖定 |
| 局部修補 | 原圖與同尺寸遮罩、一般／羽化／Fooocus 實驗流程；明確保存 PNG、CPU 合成及生成分開 |
| 結構引導 | Canny／Pose／Depth 方式可發現；顯示來源，CPU Canny 近似預覽和原引擎條件圖分開 |
| 風格參考 | SDXL 單張 IP-Adapter 畫風／角色外觀，匹配編碼器與權重；不承諾身份鎖定 |

普通 prompt 沿用 20,000 字且允許空字串，steps 1–150、一般尺寸 64–8192／8 倍數；Schnell steps 1–4、尺寸 16 倍數，專用流程另按契約，不能照抄示例「500 字必填／19 位 Seed／1–100 steps」。Seed 以十進位字串驗證至 `18446744073709551615`，不轉成 JS number。

四個常見比例 1:1／3:4／4:3／16:9，顯示實際像素與 MP。SDXL 預設 1024²、864×1152、1152×864、1536×864；FLUX 預設 512²、576×768、768×576、1024×576；SD 1.x 另按其預設。不把合法預設宣稱硬體實測。自訂尺寸在進階；非標準尺寸以最接近常見比例加「約」，例如 899×1153→約 3:4，實際尺寸不變。歷史作品保留原尺寸；修補不因比例按鈕改壞來源對齊。

模型不支援時保留停用選項與原因，不無聲替換；模型預設先比較再明確套用，不覆蓋手動值。FLUX LoRA／VAE 圖生圖是固定 512²／4 步／FP8／CPU 的獨立流程，圖生圖 Denoise＜1；FLUX 未支援修補、結構或 IP-Adapter 時，導航至獨立 Checkpoint 流程，不轉換原 FLUX 參數。

進階保留負面詞、取樣、CFG、精確 Seed、有序 LoRA、元件與來源。工具入口開啟真正的草稿／設定交換與相容性／實測；沒有一般草稿的流程用「來源與流程資訊」，不造無作用按鈕。切文字模式清除當前圖生圖來源，Denoise／縮放保留；返回需重新選圖。

遮罩使用增量點陣、requestAnimationFrame、放開筆才存快照；最多 20 次復原並有記憶體限制。筆刷／擦除、大小、羽化、反相、清除與復原／重做分組；正式[MaskEditor](../../frontend/src/MaskEditor.vue)保留筆刷1–256（預設40）、羽化0–64像素的原契約，不能縮成原型示例8–120／0–40（羽化預設10）。中央、上、下、左、右鍵盤區塊保留。Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z、Ctrl+Y 不攔截文字欄編輯；清除取消反相，區塊／反相可復原。舞台不保留舊 650px 高度上限，原圖與 canvas 使用同一容器尺寸。

預檢分環境阻擋和欄位錯誤，欄位下方關聯 aria-invalid／describedby，摘要可展開、捲動及聚焦欄位；環境入口導向實際處理頁。訊息過長局部捲動，生成與原請求恢復仍可見。後端最終驗證、凍結請求與未知結果不重送的規則保留。

主舞台顯示原任務圖片、尺寸、UUID、保存狀態和多輸出選擇；表單改尺寸不扭曲舊結果。專用畫布／結果切換保留編輯器實例。完成只表示任務成功，作品仍需明確匯入；來源、未知值、原 workflow、版本、耗時與資源不以目前環境回填。

## 作品庫與參考素材

作品固定排版為預設，保留真實比例瀑布流；用 CSS Grid 列跨度保留 DOM／排序／鍵盤閱讀順序，不用 columns 或 dense 回填，允許必要空隙。兩版共用搜尋、模型、收藏／封存、排序、分頁及選取；固定只裁縮圖。參考卡片規格為 minmax(230px,1fr)、16px gap、12px 圓角、12px 14px 內距；選取／收藏 40px 圓形，勾選 SVG 20px／1.7，收藏沿用 ★。

卡片名稱／模型各一行 `…` 和完整 tooltip，尺寸／大小、評分、日期及詳情入口分列，避免長檔名造成高度不同。素材三欄 4:3，全部／畫風／結構／角色用途及搜尋同列；用途標籤 `#293c2e` 底／`#c1d9b6` 字，僅整理用途。

作品先出現「已選 N 件／並排比較（2–4 張）／批次封存或還原／批次下載／清除」，明確按比較才進獨立比較頁。批次最多100件、原圖ZIP總量256MiB；逐件 revision、部分失敗保留、停止後續操作及未知結果不重試。返回保留篩選、選取及分頁。

點圖先開詳情；卡片不再重複展開完整資訊和單張操作。封存／還原、關閉放右上；左圖保持比例、右資訊獨立捲動。作品的筆記／評分／生成來源分頁與「載入設定」「下載原圖」分層，完整 workflow、來源與歷史仍在；素材則集中用途、尺寸、MP、大小、前處理，保留用於創作、編輯、封存及美化的另開原圖入口。圖示與文字置中，主／次按鈕均衡，長標題不推走操作。

素材沿用 PNG／JPEG／WebP、單張20MiB、1600萬像素與正規化契約。點用途帶入原素材ID與相容流程，尊重未保存確認，不自動提交、不暗改模型。空庫、封存空庫、搜尋無結果與讀取失敗分開；無結果可清搜尋／用途或模型／收藏，保留目前使用中／封存範圍。縮圖失敗保留卡片及錯誤。

## 模型、訓練與實驗

模型預設清單，可切三欄卡片，五類共用版型狀態：Checkpoint、LoRA、結構控制、參考元件、FLUX元件。頂部同步名稱、忙碌及端點跟隨分類；編輯時不能同步覆蓋。名稱、架構、尺寸／資料在左，狀態與真實操作置中或卡片靠下；版本、授權、hash、大小、來源、相容性與驗證具名展開。移除Aa／菱形等參考沒有的裝飾。只有具備安全交接的 Checkpoint 提供套用；其他類保留真正編輯／登記工具，不新增假套用。FLUX保留diffusion、text encoder、VAE角色及固定安裝計畫。

「可使用」只表示最近清單列出；缺元件、歷史未列出、離線、未知各自呈現。同步不是安裝，來源登記不是品質驗證；未知架構不猜預設或CLIP/T5角色。

訓練四階段使用22px圓形1–4、15px標題／12px副標、64px最小高度、10px圓角／8px gap。審查保留180px縮圖／原圖／主要欄位三欄、待補小圓點、已審查進度及預設勾選「只顯示待補」。來源圖片路徑／hash具名展開；保存成功才換下一張。最終評估保留不預覽，不為接近示例刪除來源審查人、角色、用途依據、分組、曝光與版本。

匯出依已保存修訂顯示描述、來源、分組／角色、原圖／完整性四組檢查；未保存不能當通過，未知阻擋碼保留。準備先顯示名稱、固定Animagine XL4.0 Opt基底及封存資料包，完整參數可展開；不合法收合欄位可定位。準備與開始分開，續訓建立新run，未知回應查原UUID。

執行摘要28px步數、6px進度條及原run狀態／讀取時間，0合法、未知不畫0%、失敗保留快照；沒有可靠總量不造620/1000。原run、日誌、資源、停止、receipt、安裝、回登、固定比較和歷史報告均具名保留，定位須展開祖先並移焦點。導覽不開始trainer。

實驗沿用原方案／結果／報告，先顯示固定模型／尺寸／提示詞／Seed與三欄組別，建立時才展開表單。方案與分組標題20px，20／28／36 steps是原型示例。載入一組只填表，逐組手動生成，不新增批次調度、自動重試或AI評分。原始JSON／hash、精確Seed、所有run與來源仍可取得。

## 系統資訊

統一1120px內容上限、左右32px，說明、結論、三摘要、分頁及面板共左緣。摘要16px gap／20px內距／14px圓角、15px標題／26px數值／12px狀態。更新與資料夾沿用參考18px SVG／1.8線寬、36px圖示按鈕，一般按鈕44px。

先顯示整體結論，例如「整體正常 · 1項尚未檢查」，需處理才暖色；空或未知是「資料待確認」，不能當零或已連線。資料來源用白話並附時間，例如「資料來源：引擎回報 · 更新於10:42」。原型只放一個「示意資料」標籤；正式頁使用真實來源。

顯存、RAM、磁碟寫「已用／總量 GB · 百分比」且數據完整只出現一處，摘要連到詳情；移除「已用／總容量」重複副標。bytes以10^9換算GB，百分比條使用未取整比例、文字取整。分類條設計色為模型`#b9d3a4`、作品`#90cbd2`、其他`#c3b1d4`；圖例三欄，上行名稱／色塊、下行粗體GB。但正式分類容量尚未完成，不用色段冒充掃描。

| 分頁 | 內容與規則 |
| --- | --- |
| 總覽 | 僅需處理及尚未檢查，附連線／元件／目錄／安裝操作。資料來源時間可具名展開 |
| 主機與引擎 | 平台主機及選定引擎分開，保留OS、Python、CUDA、驅動、每張GPU與索引、可用量、Torch、查詢失敗、無效回報、過期、CPU及容器／遠端範圍；摘要已列版本不重複 |
| 儲存與目錄 | 每磁碟一次已用／總量／比例；可用空間、磁碟區數在完整資訊。目錄摘要預設收合，展開完整路徑、異常與圖示開啟按鈕，不再列「C: · 可讀／D: · 可讀」副行 |
| 安裝與部署 | 尚未檢查空狀態＋明確檢查按鈕，檢查後才列版本裝置；保留timeout／unavailable／warnings、Python完整路徑、上次快照及環境改變可能過期。部署保留本機／遠端／容器、資料角色、URL、信任界線與更新 |

分頁列固定於57px頂欄下，鍵盤切換及摘要定位不改`#system`／history，以按鈕+scrollIntoView與焦點處理。目錄實際集合由後端決定：平台資料、素材、作品輸出、受管理checkpoint、ComfyUI輸出，加已登記額外checkpoint；原型正常共6個，不能為符合範例5個而刪功能。開啟沿用directory_id／expected_path，不接受任意路徑；未知時停用，錯誤保留。

原型正常示例：VRAM4/16、RAM24/64GB，可用12/40留詳情；磁碟1480/3000GB，模型820、作品96、其他564；可用1520GB、2磁碟在完整資訊，C680/1000、D800/2000。需注意示例C930GB／剩7%，合計1730、可用1270、其他814同步更新。這些均不是正式資料或掃描結果；只有同磁碟／同口徑／完整分類可靠才可計算「其他」，詳見N07。

## 設定

左分類190px、28px gap、右表單上限680px、20px內距／14px圓角。五類為引擎連線、模型路徑、外觀與語言、資料與隱私、診斷，使用可鍵盤切換的tabs，跨分類保留輸入。此頁依使用者要求可保留較多說明。

「測試（不保存）」唯讀指定引擎回報；「保存並套用」才改連線，不代表重啟引擎。模型路徑額外checkpoint逐行最多8個，保留預設目錄、順序、同名優先、可讀／不存在／無法讀取、修訂／衝突、重讀／捨棄、容量未知及手動重啟同步。明示只作用於本專案受管理本機引擎，不改遠端。

深色、繁中是已確認預設；未提供語言／主題清楚停用，仍用下拉外觀；未定義範圍的清快取不提供假操作。資料與隱私說明本機資料保存、遠端會傳送生成所需提示詞與輸入；封存可還原、不釋放原圖容量。設定交換入口前往真實Checkpoint／FLUX交換區，由使用者再明確匯出，JSON含創作引擎位址與參數，不是平台／作品／權重備份；完整備份沿用停機流程。診斷保留任務UUID和請求ID分開、唯讀檢查、JSON安全預覽及相同快照下載。
