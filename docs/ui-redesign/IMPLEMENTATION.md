# 正式平台介面整合紀錄

日期：2026-10-28。依本目錄 `preview.html`、`PLAN.md`、功能盤點及使用者逐頁修訂，將已確認的桌面介面套入正式 Vue 平台。HTML 仍是獨立示意原型；正式平台使用原有 API 與真實資料，不搬入原型的模型、作品、容量或任務假資料。

## 視覺對照補正

前一次整合的功能驗證不代表已逐頁符合預覽。針對使用者指出的差異，已重新對照並修正排列、主要內容起點、欄寬、畫布與預設展開狀態；本次具體差異、實測與更新截圖請見 [正式介面對照修正](ALIGNMENT.md)。下方原驗證批次保留作為歷史紀錄，本次結果以該文件為準。

## 真實資料界線與後續能力

本輪完成既有平台的介面整合，以及上述跨頁、排序、唯讀連線測試與遮罩功能。規劃內標示 N 的能力有分期，未一併實作的項目維持明確邊界：

- **N07 分類容量掃描**：現有後端只有磁碟容量，沒有可靠的模型／作品資料夾統計。正式摘要保留三欄位置，顯示「尚未統計／未知」，不代入 820／96／564 GB，不從磁碟已用量推算分類。後續需實作去重、快取、取消及部分失敗，才能顯示三段分類條。
- **N09 批次作品操作**：已於後續修正補上，見下方「作品選取與比較流程修正」。
- **N05／N06**：全域任務抽屜、跨次保存密度／展開偏好仍屬後續便利功能。
- 預檢保留既有逐項阻擋與服務端驗證，增加連線／元件處理入口；完整的跨流程統一欄位錯誤呈現仍可繼續改善。
- 桌面為本輪範圍；不以既存手機截圖或未執行的手機測試宣稱行動版完成。

## 驗證方式

測試使用拋棄式資料目錄、模擬引擎與編譯後正式前端，不操作正式作品資料，不啟動真實 GPU 生成／訓練。

- 建置：`npm.cmd run build -- --configLoader runner`。此環境的預設 Vite 設定打包器受到沙箱目錄權限限制，因此使用官方既有 runner loader；沒有變更平台打包邏輯。
- 前端：型別／CSS lint、API／生命週期／原 UUID 恢復、實驗／修補／控制契約檢查。
- 後端：清單／API／容量／環境／模型路徑／容器及新連線／排序測試，共 77 項通過。
- 瀏覽器：桌面逐頁、表單狀態、作品操作、遮罩像素、訓練與資料夾操作；實際結果於最終交付前填入下方。
- 自動無障礙檢查不等於完整讀屏、人工可用性或 WCAG 認證。

### 最終瀏覽器驗證

- 桌面針對性回歸共 32 個案例已通過；第一輪 31 個案例通過後，對新的 1280×800／1440×900／1920×1080 視窗、階段顯示與跨頁操作補跑 15 項，另補參考元件同步／保存回讀 1 項，皆通過。
- 涵蓋五種創作路由與 FLUX、網址／返回／刷新、草稿與精確 Seed、手動生成及匯入、離線讀取、作品筆記、跨頁模型／結構／角色素材、PNG 像素、來源取消、保存失敗、資料夾路徑變更、訓練原 UUID／停止／新續訓、125 張審查導航、最終評估圖不預覽。
- 十二個主要路由的 axe WCAG 2 A／AA 自動規則通過；訓練控制與審查另有自動檢查。未宣稱完整讀屏或人工 WCAG 驗收。
- 測試服務是隔離的 `scripts/browser_fixture.py`。此 Windows 沙箱的 Playwright 自動清理子程序曾卡住，因此使用暫時的 runner 設定連至自行啟停的拋棄式 fixture；正式 Playwright 設定未改。
- 沒有執行完整 134 項舊版瀏覽器測試；本輪以桌面及受影響契約為範圍，其餘舊版版面選擇器與手機情境未作通過宣告。
- Vite 建置成功，有主 JS 超過 500 kB 的提醒（約 527 kB／gzip 166 kB）；本輪未另外拆分載入。

## 作品選取與比較流程修正

作品選取先顯示與 `preview.html` 相同的深色操作列：已選件數、並排比較（2–4 張）、批次封存／還原、批次下載原圖與清除選取。選圖不再展開比較區；按「並排比較」才進入 `#/gallery/compare`。返回作品庫時，保留選取、搜尋、篩選、排序、排版及目前分頁。網址只記錄畫面，重載後沒有選取時顯示返回指引，不自動挑選作品。原圖、人工評分、精確 Seed、有序 LoRA 與完整參數差異均保留。

批次管理最多選取 100 件，比較仍限制 2–4 張。封存／還原重用既有逐件 revision 檢查；成功項目移出選取，衝突與未處理項目保留。逐項列出錯誤，提供只讀的「重新讀取選取狀態」，由使用者確認後再執行。網路中斷或結果不確定時停止後續保存，不自動重試。「停止後續操作」等待目前一件完成後停止，不撤回已成功的項目。

原圖批次下載經只讀 `POST /api/artwork-downloads` 打包 ZIP，使用已保存的 UUID 檔名，保留原始位元組與中繼資料，不連接引擎。一次最多 100 張、合計 256 MiB；缺檔、未知作品或打包失敗時不交付部分 ZIP，也不清除選取。較大的批次可分批下載。

比較與作品庫之間的瀏覽器返回／前進仍會檢查未保存筆記及評分；取消離開時保留表單及目前網址。接受離開時關閉詳情視窗，避免已離開畫面卻仍顯示舊視窗。
