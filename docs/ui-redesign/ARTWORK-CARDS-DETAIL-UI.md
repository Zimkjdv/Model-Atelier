# 作品卡片與詳情視窗調整

2026-10-29。調整正式平台，保留原始 `preview.html`。

## 作品庫卡片

- 名稱、模型檔名各佔一行，過長以 `…` 省略；滑鼠 hover 或鍵盤聚焦時以 tooltip 顯示完整文字。Tooltip 可移入、以 Escape 關閉，也能在原生詳情視窗上方顯示。
- 尺寸與檔案大小獨立成列，評分、日期與詳情入口使用一致間距。固定版型不再因檔名長度而高低不一；瀑布流仍保留圖片比例與原排序。
- 移除卡片「資訊與操作」的重複展開區。點圖片或「查看詳情」皆開啟同一個詳情視窗。
- 收藏、選取與原有批次操作保留；封存、載入設定、單張下載集中在詳情視窗。

## 詳情視窗

- 標題與收藏、封存／還原、關閉操作集中在頂欄。
- 左側保留原比例圖片，右側資訊獨立捲動；切換資訊或展開來源時，圖片與主要操作不會被推離畫面。
- 「載入創作設定」與「下載原圖」置於分頁上方。載入仍只填入工作台，不會自動生成。
- 三個分頁：作品與筆記、人工評分、生成與來源。支援左右方向鍵、Home、End，並標記未保存變更。
- 筆記、四項評分、模型／LoRA／元件快照、參考圖、執行環境、任務耗時與資源取樣、原始任務、完整工作流程與設定匯出均保留。
- 保存失敗保留草稿；切換分頁不保存或清空編輯。未保存時的關閉、重新讀取與離頁確認，以及修訂衝突保護保留。
- 修正快速關閉再開啟時，延後抵達的關閉事件清除新選取的競態；tooltip 使用獨立容器，避免影響 Vue 的內容掛載位置。

- `npm run build -- --configLoader runner`、`npm run format:check`、`npm run lint` 通過。

- 原有批次選取、明確進入比較頁、ZIP、部分衝突、停止後續寫入等六項測試通過。

- 原有未保存關閉／Escape／重整／歷史紀錄、跨視窗修訂衝突、保存失敗保留兩種草稿檢查通過。
- 來源功能的四項檢查通過：任務／作品耗時與零值／未知值、凍結資源取樣、原始整數工作流程與設定匯出、鍵盤預覽與修訂衝突。舊測試入口同步改用目前的歷史資訊、搜尋與來源分頁，未移除原有資料斷言。

正式平台截圖與數值證據保留在忽略目錄 `runtime/quality/artwork-formal-*`，不將使用者作品截圖推送至版本庫。
