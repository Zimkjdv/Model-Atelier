# 作品庫管理

作品整理、並排比較與評分集中在本文件；[並排比較與人工評分](#comparison-and-ratings)另列選取、完整參數與評分契約。以下有日期的驗收保留各次資料與裝置範圍。

作品匯入後可離線預覽、下載原圖與完整 workflow，並載入已支援流程的原始生成設定。管理資料與生成紀錄分開：收藏、筆記、封存會保存到 SQLite，圖片與任務快照保留原值。

新增的四項人工評分與管理資料共用修訂號；作品卡片可加入最多四張並排比較，操作與完整 `ratings` 格式見 [比較與評分](artwork-library.md#comparison-and-ratings)。

## 使用

- 在卡片或作品預覽中點「收藏」，再用「只看收藏」篩選。
- 預覽中的作品筆記最多 10,000 字，按「保存筆記」後保存；搜尋也包含筆記與模型版本。
- 篩選可組合使用中／已封存／全部、模型、收藏與文字搜尋。
- 「封存作品」從使用中清單移出；在「已封存」選「還原作品」即可恢复。封存後仍可下載、预览或載入生成設定。
- 筆記或評分尚未保存時，關閉預覽、載入創作設定與離開頁面有放棄變更確認；保存中避免重複操作。瀏覽器支援時，重新整理與關頁也會警示。

跨視窗更新採修訂號。收藏、筆記、封存與評分共用同一修訂；另一個視窗保存後，舊修訂回傳 409 並保留表單內容。需要重新讀取最新資料再確認修改；不自動重送或合併筆記。重新讀取有未保存筆記或評分時需先確認放棄，確認後兩者一起更新。保存評分不會代為保存筆記，兩個保存按鈕各自提交對應欄位。

## API

| API | 說明 |
| --- | --- |
| `GET /api/artworks` | 預設僅使用中作品；`scope=active/archived/all`；`favorites_only=true` 僅收藏 |
| `GET /api/artworks/{id}` | 單件資料，包含封存作品 |
| `PATCH /api/artworks/{id}/organization` | 必填整數 `revision`，至少一個 `favorite`、`notes`、`archived`、`ratings`；其他欄位拒絕 |
| `GET /api/artworks/{id}/image` | 原圖；`thumbnail=true` 縮圖、`download=true` 下載 |
| `GET /api/artworks/{id}/workflow` | 原始完整 JSON，保留精確 seed |
| `GET /api/artworks/{id}/creation-settings` | 支援流程的完整設定還原，不提交生成 |

```json
{"revision":0,"favorite":true,"notes":"記錄本次實驗的觀察"}
```

修訂不符回傳 409；UUID 不存在回傳 404；無修訂、空更新、錯誤型別、超長筆記或不可修改欄位回傳 422。更新在同一 SQLite `BEGIN IMMEDIATE` 交易讀取、比對及寫入，跨程序也不会覆蓋舊修訂。相同值的更新不增加修訂號。

新匯入作品初始化 `favorite=false`、`notes=""`、`archived=false`、`revision=0`、`organization_updated_at=null`。舊作品讀取時給相同顯示預設，不回寫歷史紀錄。重複匯入不會重設整理資料。封存仍保留參考素材引用保護；此功能不提供永久刪除或回收磁碟空間。

## 並排比較與人工評分

作品卡片按「加入比較」，最多四張。選擇順序就是欄位順序；搜尋、收藏、模型與封存篩選不會清除比較選擇。原圖等高完整顯示，參數表用「不同」標示差異，包含原引擎、流程 ID、模型版本、輸出尺寸、精確字串 seed、有序 LoRA／兩種強度及取樣／提示詞。舊流程 ID 未知不推測；輸出尺寸不代表 latent 輸入尺寸。原圖遺失時仍能比較保存參數。完整元件／參考／版本快照可從作品預覽查看。

窄視窗可在原圖與參數區橫向捲動；使用鍵盤時按 Tab 選取比較區，再按左右方向鍵。區域具有名稱、操作說明與可見焦點。

「預覽及評分」提供提示服從、角色一致、視覺風格、構圖四個分數：1 最低、5 最高，null 為未評分／不適用，不取平均填零或當作自動品質認證。用作品筆記保存評分依據。評分按「保存評分」才寫入 SQLite；比較選擇僅保留目前頁面，重新載入不保存比較組。

沿用 `PATCH /api/artworks/{id}/organization` 與作品共用修訂號。`ratings` 必須含四個欄位，每個為 1–5 的整數或 null；部分物件、bool、字串、分數超界及其他欄位拒絕。同值更新不加修訂；CAS 衝突回傳 409 且 UI 保留未保存評分，需明確重新讀取後再確認修改。未保存筆記或評分時，關閉、載入設定及離頁會保護；保存中避免重複操作。

```json
{"revision":0,"ratings":{"prompt_adherence":4,"character_consistency":null,"visual_style":2,"composition":5}}
```

新作品四項初始 null；舊作品提供只讀預設、不回填資料庫。評分只修改管理欄位及修訂時間，不改圖片、完整 workflow、模型／環境快照；重複匯入不重設評分。封存作品也可評分，不提供永久刪除。
