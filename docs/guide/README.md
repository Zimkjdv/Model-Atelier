# 圖文教學維護說明

使用者入口為 [index.html](index.html)。用瀏覽器直接開啟即可離線閱讀；保留 `guide.css`、`guide.js` 與 `images/`。不需 npm、伺服器、CDN 或外部字型。GitHub blob 頁面顯示原碼，應下載專案後開啟 HTML。列印按鈕開啟瀏覽器列印，可選另存 PDF；原生列印選單也可使用。

HTML 負責操作教學，既有 Markdown 保留安裝命令、資料契約與驗收證據，避免複製成兩套開發規格。HTML 的深入連結會開啟本機 Markdown，依瀏覽器可能顯示純文字或下載，可改用編輯器閱讀。更新介面名稱／流程時一併核對本教學與圖片說明；資料出口通過、技術訓練成功與作者品質通過須明確分開。

## 檢查方式

T08 新增 `images/training-report.png`，取自 `runtime/t08-native-1440.png`：原生平台以隔離 DATA 登記既有幾何圖 run，只讀預覽與下載報告，無 API 寫入、無新訓練。原 T06 訓練全頁仍保留當時驗收畫面，新增操作另以 T08 圖與步驟說明。

T07 更新後重拍資料審查全頁，加入搜尋、用途／缺項篩選、定位與完整分頁；仍為同一個隔離自製色塊案例。作者圖片的待審查狀態不變。

以 Chromium 分別在 1440px 與 390px 開啟本機 HTML，檢查無水平溢出、圖片完整、章節跳轉、圖片放大／Escape 關閉、列印展開與鍵盤焦點；執行 axe WCAG A／AA 檢查。另核對 HTML 本機連結、圖片與章節目標。只改文件時不需執行 GPU 訓練或生成。
