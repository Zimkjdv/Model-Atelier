## 更新及檢查

先核對正式 Vue 元件、主題文件與實際頁面，再更新文字與截圖。沿用正式 `UiIcon.vue` 的 SVG 路徑、22px 大小與筆畫，避免另畫一套相似圖示。新增圖需記錄來源及狀態，不將作者原圖、資料包或權重放入 `images/`。

以 Chromium 直接開啟本機 HTML，核對 1280×800、1440×900、1920×1080；教學本身另檢查 390px。檢查章節跳轉、所有圖片載入、沒有整頁橫向溢出、圖片放大／Escape／焦點還原、無 JavaScript 的基本閱讀、離線資源、列印展開及結束還原。axe 自動檢查僅代表所用規則結果，不等於完整讀屏或列印認證。

只改教學不需執行 GPU 生成／訓練；發現不合理流程時先在 ROADMAP 記錄實際情境、影響與驗收條件，不在截圖中掩飾問題。

## 2026-10-30 實際檢查結果

四種視窗尺寸均無整頁水平溢出，14 張截圖全部載入。直接以 `file://` 在離線狀態驗證章節跳轉、目前章節提示、Enter 放大、Escape／按鈕關閉、焦點還原、無 JavaScript 導覽與原圖連結，以及列印前展開／結束還原；頁面例外、遺失資源及遠端請求皆為 0。73 個本機資源／文件／章節連結與 31 個唯一 ID 核對通過。

相同靜態檔另透過 loopback 提供給 axe，以避免 Chromium 對 `file://` 樣式表 CSSOM／XHR 的限制。四種尺寸的 WCAG 2A／2AA／2.1AA 自動違規皆為 0；`color-contrast` 仍有符號、偽元素及背景無法自動判定的 incomplete，另核對主題文字、步驟編號、程式碼與放大標籤等 11 組色彩，對比為 6.77–15.81。桌面、390px 及列印模擬另經截圖檢視；這不是完整讀屏、觸控或實體印表機認證。

本機檢查摘要在忽略的 `runtime/guide-validation.json`；UX01 的隔離重現摘要在 `runtime/guide-progress-issue.json`。本輪沒有執行產品全套回歸或 GPU 工作。
